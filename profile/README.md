## Featured projects

- **[Siyana-Lang](https://github.com/siyana-code/Siyana-Lang)** — a general-purpose language built for one constraint: writing an operating system without an external toolchain.
- **[Siyana-Markdown-Viewer](https://github.com/siyana-code/Siyana-Markdown-Viewer)** — a fast, safe, local-first Markdown viewer. No account, no upload, no telemetry. `MIT`
- **[Siyana-Debt-Tracker](https://github.com/siyana-code/Siyana-Debt-Tracker)** — a private, offline-first ledger for the money you lend and borrow. `MIT`
- **[maths-guru-website](https://github.com/siyana-code/maths-guru-website)** — free maths learning for Sri Lankan students, Grade 6 to O-Level.
- **[Siyana-OS](https://github.com/siyana-code/Siyana-OS)** — a hobby x86_64 operating system in Rust and assembly.
- **[Siyana-Chat](https://github.com/siyana-code/Siyana-Chat)** — a messaging app whose log is authoritative on both sides.

## How I work

1. **Research the problem** — written down, in plain English, next to the code.
2. **Write the decisions** — ADRs and a decision log. If it isn't written down, it isn't decided.
3. **Build in the open** — public from the first commit, in small reviewed commits.
4. **Ship one real thing** — finished and usable beats ten half-built ideas.
